Основні команди Git

1. Ініціалізація та статус

git init
git status
git add .
git commit -m "Повідомлення"

2. Робота з гілками

git branch
git checkout -b назва_гілки
git checkout develop
git merge task_1.12

3. Робота з GitHub

git remote add origin URL
git push -u origin develop
git pull

4. Інші корисні команди

git log --oneline
git clone URL
git reset
git stash
